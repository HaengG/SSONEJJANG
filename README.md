# 내소네 레시피북

카페 레시피북을 외우기 위한 아이폰용 웹앱(PWA)이에요. 서버 없이 폰 안에만 기록을 저장해요.

## v0.2 게임 모드

- **문제는 전부 탭 한 번**: 숫자 고르기 / 아이스·핫 / 어디에 담아요(샷잔·바로 잔) / 메뉴 맞히기 / O·X / (순서형) 다음 단계
- **오늘의 주문**: 간격 반복으로 고른 복습 메뉴 + 새 메뉴(소개 카드 → 문제). 오늘 몫이 끝나도 **한 판 더**로 계속할 수 있어요.
- **스테이지**: 패밀리 하나 = 스테이지 하나. 별 1~3개, 별을 따면 다음 스테이지가 열려요.
- **콤보·XP·바리스타 등급**: 견습 → 바리스타 → 시니어 → 헤드 → 점장
- **주문 러시**: 60초 O/X 최고기록 도전 (복습 일정에는 영향 없음)
- 틀린 문제는 판 끝에 한 번 더 나와요. 목숨 제한과 효과음은 없어요.
- 문제 생성: `src/lib/questions.ts`, 판 구성·등급: `src/lib/game.ts`

## 1차 MVP에 들어간 것 (연습실·레시피북에 그대로 있어요)

| 기능 | 설명 |
|---|---|
| 오늘의 학습 | 간격 반복(FSRS)으로 오늘 복습할 메뉴와 새 메뉴(기본 하루 5개)를 자동으로 골라요 |
| A. 플래시카드 | 메뉴 이름과 칸 틀만 보고 떠올린 뒤, 모름/어려움/알맞음/쉬움으로 평가해요 |
| B. 빈칸 채우기 | 숫자 빈칸과 보기 문제예요. 숙련도가 오를수록 빈칸이 늘어나요 (쉬움 → 보통 → 어려움) |
| G. 패밀리 보기 | 비슷한 메뉴의 공통 뼈대와 메뉴별 차이(형광펜), 핫/아이스 나란히 비교 |
| 레시피북 | 검색, 카테고리 필터, 수정·추가·삭제 폼 |
| 연습실 | 복습 일정에 영향 없이 자유 연습 |
| 대시보드 | 숙련도 지도(원두 로스팅 단계), 헷갈리는 메뉴 TOP 5, 연속 학습일 |
| 백업 | JSON 파일로 내보내기·불러오기 (아이폰은 공유 → "파일에 저장") |

### 숙련도 단계와 출제 방식

| 단계 | 조건 | 출제 |
|---|---|---|
| 0 새 메뉴 | 아직 안 배움 | 소개 카드(레시피 + 패밀리 팁 + 핫/아이스 비교) → 플래시카드 |
| 1 익히는 중 | 학습/재학습 중 | 플래시카드 |
| 2 조금 앎 | 안정도 5일 미만 | 플래시카드 또는 빈칸(쉬움) |
| 3 거의 앎 | 15일 미만 | 빈칸(보통) |
| 4~5 잘 앎/마스터 | 그 이상 | 빈칸(어려움) |

## 실행

```bash
npm install
npm run dev      # 같은 와이파이의 아이폰에서 http://<PC IP>:5173 으로 접속 가능
npm run build    # dist/ 생성
```

## 배포 (GitHub Pages)

1. 루트의 `deploy-pages.yml`을 `.github/workflows/deploy.yml`로 옮겨요.
   (원격 작업으로는 `.github` 폴더에 파일을 쓸 수 없어서 루트에 두었어요.)
1. 이 폴더를 GitHub 저장소로 push해요 (`main` 브랜치).
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꿔요.
3. push할 때마다 워크플로가 빌드해서 배포해요.
4. 아이폰 사파리로 주소를 열고 **공유 → 홈 화면에 추가**를 눌러요.

`vite.config.ts`의 `base: './'` 덕분에 `https://<id>.github.io/<repo>/` 하위 경로에서도 그대로 동작해요.

## 레시피 수정

- 원본 데이터는 `src/data/recipes.ts`예요. 한 줄 = 외울 단위 하나예요.
  - 숫자는 빈칸 문제가 돼요.
  - `📍 샷잔`, `📍 바로 잔`처럼 위치는 따로 한 줄로 둬요.
- 앱 안의 수정 폼으로 바꾼 내용은 폰에만 저장돼요. 설정 → "레시피를 원본으로 되돌리기"로 원본에 맞출 수 있어요.
- `recipes-draft.md`는 종이 레시피북을 옮겨 적은 확정본이에요.

## 구조

```
src/
  data/recipes.ts        레시피 71개 + 패밀리 정의
  lib/srs.ts             FSRS 간격 반복, 숙련도 계산
  lib/cloze.ts           빈칸 문제 생성 (숫자 빈칸 + 보기 함정)
  lib/recipe-utils.ts    핫/아이스 비교, 패밀리 뼈대 계산
  lib/db.ts              IndexedDB 저장, 백업/복원
  store.tsx              앱 상태
  screens/               홈, 학습 세션, 레시피북, 연습실, 설정
  components/            레시피 카드, 플래시카드, 빈칸, 비교 뷰
```
